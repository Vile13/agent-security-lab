Remote access uses the company VPN with a hardware token as the second factor.
Install the client from the internal software portal, then enrol your token at
intranet.example.com/enrol.

Split tunnelling is disabled. All traffic from an enrolled device is routed
through the corporate egress gateway while the VPN is connected.
